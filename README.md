# TerraQDT

Versões publicadas do TerraQDT (distribuição de terraplenagem por menor DMT).

O programa confere o `versao.json` ao abrir e se atualiza sozinho (botão dourado no topo).
Para instalar à mão: baixe o `TerraQDT.exe`, coloque numa pasta sua e abra.

Versão atual: **0.13.0**. O código-fonte não está aqui.
